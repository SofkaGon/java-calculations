What is Java?

Java is a programming language: a way of writing instructions that a computer can follow. It was created in the 1990s and is still one of the most widely used languages in the world.

A Java program is written as plain text in a file ending in .java. Here is the smallest useful example:

System.out.println("Hello World");

This one line tells the computer to display the words Hello World.

Main characteristics

Object-oriented
Programs are organised into classes and objects (see below).
Platform independent
The same compiled program can run on Windows, macOS and Linux. This is often called "write once, run anywhere".
Statically typed
You must say what kind of data a variable holds (int for whole numbers, String for text). Many mistakes are caught before the program runs.
Compiled and interpreted
Your code is first compiled, then run by the Java Virtual Machine.
Automatic memory management
Java cleans up memory you are no longer using (garbage collection).
Large standard library
Ready-made tools for input, text, dates, collections, graphics and more, such as Scanner for reading user input.

Why learn Java?

  • It teaches core ideas (variables, conditions, loops, classes) that carry over to other languages.
  • Clear rules and strong error messages help beginners find mistakes.
  • It is in demand for jobs and used in many courses.
  • It has a huge community, documentation and free tools.

Introduction to object-oriented programming (OOP)

OOP is a way of organising a program around things. A class is a blueprint; an object is something built from that blueprint.

Example: a Rectangle class describes what every rectangle has (a width and a height) and what it can do (calculate its area). Each rectangle you create is an object with its own width and height.

  • Class: the blueprint.
  • Object: one thing made from the blueprint.
  • Fields: the data an object holds.
  • Methods: the actions an object can perform.

Every Java program lives inside a class, even a very small one. You will meet this in the first lesson.

How Java code becomes a running program

Computers do not understand Java text directly. It goes through these steps:

  1. Write source code in a .java file, for example Hello.java.
  2. Compile it with the Java compiler (javac). It checks for errors and produces bytecode in a .class file.
  3. Run the bytecode with the Java Virtual Machine (java).
  4. The JVM translates the bytecode into instructions for your computer, and the program runs.
Hello.java  --javac-->  Hello.class  --java (JVM)-->  program output

In a terminal this looks like:

javac Hello.java
  java Hello

Many people use an IDE (a code editor with Java support), which does these steps when you press "Run".

The JVM (Java Virtual Machine)

The JVM is a program that runs Java bytecode. Think of it as a translator that sits between your Java program and the operating system.

  • There is a different JVM for each operating system, but they all understand the same bytecode. That is why one compiled program works on many systems.
  • It manages memory and cleans up unused objects.
  • It checks bytecode before running it, which adds a layer of safety.

You will usually see three names: the JVM (runs programs), the JRE (JVM plus libraries, for running) and the JDK (JRE plus the compiler and tools, for writing). To write Java you need the JDK.
