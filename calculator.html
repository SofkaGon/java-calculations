Official download source

The only official download location is the GitHub Releases page of this project. Do not use copies from other websites.

Verify your download

Compare the SHA-256 checksum of the file you downloaded with the one shown above. If they differ, do not run the file.

  • Windows (Command Prompt): certutil -hashfile FILENAME SHA256
  • macOS / Linux: shasum -a 256 FILENAME

Hosting on GitHub does not by itself guarantee that a file is safe. A checksum only proves the file matches what the author published. Only run software from sources you trust.
